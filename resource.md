# 📌 Learning Philosophy

While solving problems, I try to follow this workflow:

1. Understand the problem.
2. Think of a brute-force solution.
3. Optimize the approach.
4. Analyze time and space complexity.
5. Implement clean, readable code.
6. Document key takeaways.
7. Revisit difficult problems for reinforcement.
